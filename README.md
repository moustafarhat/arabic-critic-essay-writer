This skill was generated by [PersonaWriter](https://github.com/moustafarhat/PersonaWriter) from one
long-form Arabic music-criticism essay (about 2,500 words), then tested on unrelated topics and
refined. It is a complete, real example of what PersonaWriter builds: a style guide made of
*decisions*, a never-list, measured dosage, and scripts that check every draft.

## What it produces

The output is always **Arabic (formal MSA)**, even if you ask in English or German.

| Ask for | You get |
|---|---|
| A review of an album, film, book, series, exhibition or game | A 900-1,400 word essay that finds the work's central tension, reads it through a few small details, gives the work its fairest objection, and closes without a star rating |
| An essay on a social habit or cultural trend | The same argument shape applied to a habit: voice messages, photo hoarding, a new slang word |
| A long-form analysis of an artist or a body of work | Periods placed on an axis, then an argument for why the new work changes the axis |
| An opinion piece with a critic's voice | A qualified, fair argument that concedes the awkward fact instead of preaching |
| "Rewrite this review in the critic's voice" | Your facts, names and quotes kept, the structure rebuilt around an argument, plot or tracklist summary dropped |
| Short forms (600-1,000 words), and plain announcements or emails | A lighter version: one image, one first-person pivot, same open ending; for plain copy only the negation opener and calm hedges carry over |

**The voice in brief:** long sentences that build a qualified claim, then a short, blunt one that
lands it. "Not X, but Y" (ليس ... وإنما) as the engine of every thesis. The work treated as an
agent that bets and insists. One hedge and one precision word per claim. One everyday image per
abstraction. No exclamation marks, no lists, no superlatives, no «في الختام».

## Use it

Just ask. For example:

- «اكتب مراجعة لألبوم ... بأسلوب الناقد»
- «مقال نقدي بنفس الأسلوب عن ظاهرة ...»
- "Write a review of this film in the critic's voice" (the essay comes back in Arabic)
- Paste a flat review and say «أعد كتابتها بهذا الأسلوب»

Dials you can turn: the critic's presence (more or less first person), the weight of the
concession, sentence length, how much is quoted, and length.

Give it facts. The skill will not invent quotes, lyrics, scenes or dates. If it doesn't know a work
well enough, it asks for notes or writes only about what you supplied.

## How drafts are checked

The skill checks its own drafts with PersonaWriter's `style_stats.py` (standard-library Python 3.9+):

```bash
cd skills/arabic-critic-essay-writer
python scripts/style_stats.py compare references/profile.json draft.txt   # rhythm score + top fixes
python scripts/style_stats.py check references/markers.json draft.txt     # dosage + never-list
python scripts/style_stats.py overlap draft.txt references/anchors.md     # nothing copied
```

`markers.json` encodes the style's signature moves with target rates (for example 3-9
negation-then-correction frames per 1,000 words) and its never-list (exclamation marks,
superlatives, «في الختام», stand-alone «أنا», AI filler like «من الجدير بالذكر»).

## Limits

- **Provisional profile:** learned from one essay, one genre (music criticism). Other genres are
  marked as inference in the style guide.
- The source reads like a translation from English criticism. The skill is told to write native,
  idiomatic Arabic and not to copy its calques.

## Ethics

The skill stores patterns and six one-sentence anchors, never passages of the source. The source
essay is not named, and output is original writing in a manner, never presented as the source
author's work. No invented quotes or facts.
